# Tableau Workbook

The completed Tableau package is `Consumer_Market_Intelligence_COMPLETE_READY.twbx` in the project artifacts.

It contains three dashboards:

1. **Executive Overview** — business KPIs, revenue trend, category, region, products, and channels.
2. **Consumer Insights** — customer value, frequency, segments, age groups, and segment/channel behavior.
3. **Product & Market Intelligence** — product ranking, category growth/trends, and region × category analysis.

The workbook was built from the synthetic Consumer Market Intelligence dataset. The connected market benchmark table was intentionally not used in the Tableau data model, so company revenue mix is not mislabeled as real market share.

Because the available GitHub connector accepts UTF-8 text for file creation but does not accept a local binary-file reference, the `.twbx` binary is retained in the project artifacts and should be added to this folder when the repository is finalized locally.
