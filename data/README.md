# Data

The project dataset is the synthetic `Consumer_Market_Intelligence_Dataset.xlsx` workbook used during analysis.

Workbook contents:
- README
- Data_Dictionary
- Customers — 8,000 rows
- Products — 45 rows
- Transactions — 60,000 rows
- Calendar — 731 dates
- Market_Benchmark — 3,600 synthetic benchmark rows

The workbook contains synthetic portfolio data and no real customer/company data.

The binary workbook is kept with the project artifacts in the ChatGPT workspace because the connected GitHub action available here accepts UTF-8 text for file creation but does not accept a local binary-file reference. It should be added to `data/` when the repository is cloned and finalized locally.
